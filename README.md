## ➕ Ajouter un jeu ou un site

1. Créer un dossier à la racine du dépôt (ex. `voxarion/`) contenant le projet, avec si possible
   un `index.html` jouable directement et un petit `README.md`.
2. Ajouter une ligne dans le tableau correspondant ci-dessus (nom, description, lien vers le dossier).

> Astuce : en activant GitHub Pages sur ce dépôt (Settings → Pages → branche `main`), chaque jeu
> devient jouable en ligne à l'adresse `https://<utilisateur>.github.io/games/<dossier>/`.
